# mesura2-releases

Descargas públicas de **Mesura2** / **Mesura2 Pro**, el medidor de energía de tu notebook para Windows:
watts en vivo, cuánto aporta cada cargador, autonomía real y salud de la batería, de
[In2Dev](https://in2devapps.com).

Este repo **no tiene código fuente**: solo existe para publicar el instalador (`.exe`) en
[Releases](https://github.com/alejandrobricker-in2dev/mesura2-releases/releases), de forma pública
y gratuita (GitHub Releases no cobra por transferencia). El código real vive en un repo privado
aparte.

## Descargar

Última versión: [Mesura2Pro.exe](https://github.com/alejandrobricker-in2dev/mesura2-releases/releases/latest/download/Mesura2Pro.exe)

Más información, manual de uso y Términos y Condiciones en
[in2devapps.com](https://in2devapps.com/proyectos/mesura2.html).
